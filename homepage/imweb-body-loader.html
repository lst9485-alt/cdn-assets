아임웹 본문 동적 로더 (4페이지 공용)

사용법: 각 아임웹 페이지의 코드 위젯에 아래 블록을 붙여넣으세요.
data-page 속성만 다르고 나머지는 동일합니다. 정본 push 즉시 반영(캐시 무효화).

1. 메인 / (data-page="main-page")

대상 변환본: main-page-imweb.html 
<div id="hpx" data-page="main-page" style="min-height:400px;background:#fff"></div>
<script>
(function(){var d=document.getElementById('hpx');var n=d.dataset.page;
var u='https://lst9485-alt.github.io/cdn-assets/homepage/'+n+'-imweb.html?t='+Date.now();
fetch(u).then(function(r){if(!r.ok)throw 0;return r.text()}).then(function(h){
var t=document.createElement('template');t.innerHTML=h;
Array.from(t.content.querySelectorAll('script')).forEach(function(s){
var x=document.createElement('script');for(var a of s.attributes)x.setAttribute(a.name,a.value);
x.text=s.textContent;s.parentNode.replaceChild(x,s)});
d.innerHTML='';d.appendChild(t.content)}).catch(function(){
d.innerHTML='<p style="padding:40px;text-align:center;color:#888">페이지를 불러오지 못했습니다. 새로고침 해주세요.</p>'})
})();
</script>

핵심 동작 메모

  • script 실행 보장: template로 파싱 후 모든 <script>를 새 노드로 교체(innerHTML로는 실행 안 됨).
  • 캐시 무효화: ?t=Date.now()로 push 즉시 반영.
  • 깜빡임 최소화: 컨테이너에 min-height:400px;background:#fff 유지.
  • 에러 폴백: fetch 실패 시 안내 문구 표시.
  • 모바일 호환: vanilla JS, IE 제외 모든 모던 브라우저 OK.
