06 가격 섹션 — 클로징 박스 시안 비교

현재 → 시안 A → B → C → D 순서. 톤·메시지 다 다른 4가지.

현재 (참고용)

사고 후회하지 말고, 사기 전에!

내 예산에 맞는 최고의 내집마련
구체적으로 알려드립니다!

"혼자 판단하기 전에 기준을 먼저 잡은 게 가장 컸습니다"

— 서울 성동 30대 이*나 님 · 실제 코칭 후기

시안 A — 후회 → 안심 (현재 톤 강화 + 강한 후기)
변경: 헤드라인 구조 유지 + 후기 더 강한 인용 ("수억 수업비")으로 교체. 실거래 안목 강조.

사고 후회하지 말고, 사기 전에!

내 예산에 맞는 최고의 내집마련,
실거래 안목으로 찾아드립니다

"수억의 수업비를 내기 전에 만났다면
얼마나 좋았을까 싶습니다"

— 서울 40대 자영업자 김** 님 · 실제 코칭 후기

시안 B — 시행착오 단축 (시간·돈 절약 가치)
변경: "시행착오 = 수년·수억 절약" 메시지. 후기 키워드 1위(방향) + 강한 가치 환산.

혼자 헤맬 수년의 시간,

한 번의 코칭으로
줄여드립니다

"수년의 시간과 수억의 수업비를
아낄 수 있었습니다"

— 실제 코칭 후기

시안 C — 받는 결과 약속 (구체적 산출물)
변경: "예산 → 입지 → 매수"까지 받는 결과를 시각화. 후기 빈출(로드맵·구체적) 키워드 반영.

막막했던 내집마련, 끝.

예산 → 입지 → 매수까지
한 번에 정리해드립니다

✓ 내 예산 분석 ✓ 맞춤 입지·단지 ✓ 매수 타이밍 ✓ 대출 전략

"자산을 어떻게 키워나갈지
로드맵이 머릿속에 그려졌습니다"

— 실제 코칭 후기

시안 D — VS 비교형 (변화 大)
변경: 박스 안에 좌우 비교(혼자 vs 코칭). 가장 임팩트 강함. 시각 변화 大.

같은 내집마련, 다른 결과

혼자 결정할 때

  • ·유튜브·블로그 정보 짜집기 (수개월)
  • ·끝없는 망설임
  • ·잘못 매수 = 수억 손실 위험

코칭 후 결정할 때

  • ·내 맞춤 로드맵 1회로 정리
  • ·실거래 안목으로 확신
  • ·수년 시행착오 단축

한 번의 결정이 인생을 바꿉니다

"수년 시행착오를 한 번에 줄여주셨습니다"

— 실제 코칭 후기
